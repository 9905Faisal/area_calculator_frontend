AREA CALCULATOR FRONTEND
========================

Files:
- index.html             Website layout
- style.css              Styling and responsive design
- script.js              Browser-side calculator logic
- calculator_class.cpp   Your supplied C++ console program

HOW TO RUN:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another browser.
3. Enter the measurements and click "Calculate area".

NOTE:
Browsers do not execute a standard C++ source file directly. This frontend
implements the same formulas in JavaScript so the calculator works locally.
The original C++ program is included separately.
